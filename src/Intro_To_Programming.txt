Type of Languages
(1) Procedural
	-specifies a series of well-structured steps and procedures to compose a program.
	-contains a systematic order of statements, functions and commands to complete a task

(2) Functional
	-writing a program only in pure Functions i.e. never modify variable, but only create new ones as an output
	-used in situations where we have to perform lots of different operations on the same set of data, like ML

(3) Object Oriented
	-Revolves around objects
	-code + data = object
	-developed to make it easier to develop, debug, reuse, and maintain software


Static vs Dynamic Languages
(1) Static
	-performs type checking at compile time
	-errors will show at compile time
	-declare datatype before you use it
	-more control

(2) Dynamic
	-performs type checking at runtime
	-error might not show till program is run
	-no need to declare datatype of variable
	-saves time in writing code but might give error at runtime


Stack and Heap Memory
	let's say -> a = 10
	here 'a' is "reference variable (just a poniter)" and is stored in stack Memory
	and '10' is the "object" stored in heap memory 

	The variables in stack memory is just pointing towards objects in stack memory

	More than one reference variable can point to the same object
	If any one of the reference variable changes the value of the object, the value of real object will be changed for all reference variable 


Garbage Collection
	All the objects which don't have any reference variable pointing todwards them will be deleted/removed
	Example - a = 10
			  a = 12

			  here we allocate 12 to 'a' so now 10 is an object without any reference variable
